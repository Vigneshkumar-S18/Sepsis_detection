1. Executive Summary & Clinical Impact

Sepsis is a life-threatening condition where delayed medical intervention dramatically increases mortality. **SEPSIS AI** is a state-of-the-art Clinical Decision Support System trained on 40,336 ICU patients (1.55M hourly records) from the PhysioNet 2019 Challenge dataset. The system engineered **391 clinical features** and trained deep temporal neural networks to issue alerts hours before clinical manifestation.

Unique Patients 10,616 Cohort A & B Dataset
Feature Dimensions 391 Vitals, Labs, Slopes, Sparsity
Sequence Tensors 1,330,534 3D NPZ Sliding Windows

3. Early Warning Lead-Time Analysis

The BiLSTM sequential champion model maintains strong early detection capability up to 6 hours ahead of clinical sepsis onset:

  • 0-Hour Current Detection (w12_h0): Test AUROC = 0.7899, Recall = 56.69%
  • 3-Hour Advance Warning (w12_h3): Test AUROC = 0.7666, Recall = 58.33%
  • 6-Hour Advance Warning (w12_h6): Test AUROC = 0.7529, Recall = 28.47%
